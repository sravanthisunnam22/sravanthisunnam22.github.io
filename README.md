# Sravanthi Sunnam | SDET & QA Portfolio

Live portfolio: https://sravanthisunnam22.github.io/

Public viewing is enabled. Repository write permissions control who can edit; viewing or forking does not grant permission to change this site.

The root contains the ready-to-publish GitHub Pages build. GitHub Pages publishes from main, root.

## Editing and rebuilding

Source is in `portfolio-source/`. With Node 22.13 or later, run `npm install` and `npm run build` there. Copy the contents of `pages-build/` into the repository root, then commit the source and generated files together. Keep `.nojekyll`.

The contact form opens an email draft and does not send or store submissions. Playwright is presented as completed training.
